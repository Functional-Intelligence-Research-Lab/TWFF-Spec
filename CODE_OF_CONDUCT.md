# Code of Conduct

TWFF is a small project built by a small team, with contributions from outside it. These rules
apply to the issue tracker, pull requests, and any other space the project uses for discussion.

- Be welcoming. People come to this from different backgrounds, disciplines, and levels of
  experience. Treat that as normal, not as friction to manage.
- Be respectful. Disagreement is fine; personal attacks, harassment, and exclusionary language
  aren't. If someone asks you to stop, stop.
- Assume good faith. If a disagreement is confusing, ask why before assuming bad intent.
- No doxxing, threats, sexually explicit or violent content, or discriminatory language or jokes.

Violations can be reported by emailing [muhsin@firl.nl](mailto:muhsin@firl.nl).

Adapted from the [Speak Up! project](http://web.archive.org/web/20141109123859/http://speakup.io/coc.html).
