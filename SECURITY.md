# Security

If you believe you've found a security vulnerability in this project or in
any Functional Intelligence Research Lab product (firl.nl, colophon.firl.nl,
the Colophon browser extension, or the TWFF specification), please report it
privately rather than opening a public issue.

**Contact:** hello@firl.nl — include as much detail as you can (steps to
reproduce, affected component, potential impact). We'll acknowledge your
report and follow up as we investigate.

Please give us a reasonable amount of time to address a reported issue
before disclosing it publicly.
